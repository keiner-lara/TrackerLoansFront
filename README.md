# TrackerLoans – Front

React + Vite + TypeScript + Tailwind, instalable como PWA.

- `cp .env.example .env` (`VITE_API_URL` = URL del back) · `npm run dev` · `npm run build`
- Despliegue: Cloudflare Pages / Vercel (build `npm run build`, salida `dist`, variable `VITE_API_URL`).
- En el celular: abrir la URL → "Agregar a pantalla de inicio" → activar los avisos dentro de la app.
